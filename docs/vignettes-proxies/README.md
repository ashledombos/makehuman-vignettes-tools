# Les 29 vignettes de proxies, telles que livrées

Ce dossier existe pour une raison précise : **ne plus jamais reconstituer ce lot
en agrégeant les dossiers de rendu par régime**.

Un asset dont la vignette retenue est un composé — `jujube_proxy_with_helpers_test`
est un diptyque empilé — figure dans ces dossiers sous sa version abandonnée,
parce que le composé est produit dans un second temps et rangé ailleurs. En
septembre 2026, un lot reconstitué ainsi donnait 28 vignettes bonnes et une
fausse, et la fausse ne se voyait qu'à l'œil.

Ces 29 fichiers sont ceux versés dans `thumbnail_overrides/` du dépôt d'assets.
Ils font foi.

| régime | quand | combien |
| --- | --- | ---: |
| global | le proxy est neuf à plus de 90 % | 4 |
| local | la zone retravaillée tient sur moins de 35 % du corps | 12 |
| dispersé | ni l'un ni l'autre | 12 |
| diptyque empilé | deux foyers éloignés, exception unique | 1 |

Décor commun : fond noir opaque, corps porcelaine, encre bleue, une seule
couleur pour tout ce qui parle du maillage.
